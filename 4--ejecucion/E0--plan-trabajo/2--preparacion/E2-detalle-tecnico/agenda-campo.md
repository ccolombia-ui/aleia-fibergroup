# Agenda · Técnicos de Campo (Frente D) · Sprint 2 · E2

## Rol en este sprint

En E2 el Frente D entrega datos de **infraestructura existente** por municipio: el Formulador necesita saber qué hay actualmente en el territorio para dimensionar la solución técnica.

> Nota: si los datos de infraestructura ya fueron entregados en E1, esta agenda se reduce a disponibilidad para consultas y complementos.

## Tabla de infraestructura requerida (por municipio)

| Campo | Descripción |
|-------|-------------|
| Municipio | Nombre + código DIVIPOLA |
| Infraestructura existente | Tipo: fibra / coaxial / radio / ninguna |
| Operador actual | ISP que opera en el municipio (si aplica) |
| Cobertura actual | % hogares / IEs con conectividad |
| Nodos / repetidoras | Ubicación y capacidad si existen |
| Puntos de agregación | Donde puede conectarse nueva red |
| Observaciones campo | Dificultades de terreno, acceso, actores |
