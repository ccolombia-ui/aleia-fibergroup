## Datos mínimos requeridos por municipio (formulario estándar)

| Campo | Descripción |
|-------|-------------|
| Nombre municipio | Identificador DIVIPOLA |
| Cobertura internet actual | % hogares / IEs con internet |
| Tipo de infraestructura existente | Fibra / coaxial / radio / ninguna |
| Número de IEs sin conectividad | Escuelas, colegios, centros comunitarios |
| Población beneficiaria estimada | Hogares + IEs + sector productivo |
| Observaciones de campo | Dificultades de acceso, actores locales clave |
